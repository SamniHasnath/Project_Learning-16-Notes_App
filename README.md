# 📝 Notes App

A simple, sleek, and functional Notes App designed to help you capture your thoughts instantly. Whether you're on a desktop or mobile, your notes stay synced and organized.

---

## 🚀 Features

This app is built to be lightweight and user-friendly, providing all the essential tools for note-taking:

* ✍️ **Create Notes:** Easily add new notes with a title and detailed content.
* 📄 **View All:** A clean dashboard to browse through all your saved notes.
* 🗑️ **Delete:** Remove notes you no longer need with a single click.
* ✏️ **Edit:** Update your existing notes to keep information current.
* 💾 **Dual Storage:** Options to save notes locally in your browser or persist them in a PostgreSQL database.
* 📱 **Responsive Design:** Optimized for a seamless experience on both mobile and desktop.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript,React (ES6+)
* **Backend:** Node.js, Express
* **Database:** PostgreSQL (via `pg` pool)
* **Environment:** Cross-platform (Mobile & Desktop)
